# Tile Game

A simple 2D tile-based game built with **Java** and **AWT**.

## Features

- Tile-based game world
- Player movement
- Camera system
- Game states
- Keyboard input
- 60 FPS game loop
- Countdown timer
- Win state

## Tech Stack

- Java
- Java AWT
- BufferStrategy
